Geschützter lokaler Speicher

Die Daten bleiben auf diesem Gerät und werden mit einem selbst gewählten Passwort verschlüsselt. Das Passwort wird nicht gespeichert und kann nicht wiederhergestellt werden.

Ohne Passwort und ohne Sicherungsdatei können die Daten bei Geräteverlust nicht wiederhergestellt werden. Bitte zusätzlich verschlüsselte Backups auf einem zweiten Gerät aufbewahren.

🔒 Lokal verschlüsselt · Datenübertragung: keine · Noch kein externes Backup
Lokale Testversion V3: Kundendaten werden im Browser verschlüsselt gespeichert und nur lokal verarbeitet. Zusätzlich regelmäßig eine verschlüsselte Sicherung auf einem zweiten Datenträger speichern! Browserdaten können verloren gehen. Kein gleichzeitiges Arbeiten auf mehreren Geräten, keine automatische Cloud-Sicherung. Vor Echtbetrieb Geräte-/Druck-/Wiederherstellungstests erforderlich.
